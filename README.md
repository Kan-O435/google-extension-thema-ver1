# Ayusama-haikei

自分の好きな背景に差し替えられる、Chrome 向けの「テーマ風」新しいタブ拡張機能 (Manifest V3)。

## 特徴

- **曜日ごとに背景画像が切り替わる**(日〜土、ローカルタイムで判定。日付をまたいでも自動で再評価)
- 背景は縦長画像 3 枚の横並び表示。画像は登録した中からランダムに選ばれる
- アイコン付き**ショートカット**を複数登録(favicon 自動取得、追加・編集・削除)
- 新しいタブの登場アニメーション・パーティクル・ホバー演出
- 完全ローカル動作。画像・URL・閲覧情報を外部へ送信しない

> Chrome 公式の「テーマ」では曜日切り替えができないため、`chrome_url_overrides.newtab` で新しいタブを差し替える方式にしています。ブラウザ上部のバーの色は拡張からは変更できないため、別パッケージのテーマ(`theme/`)を併用します。

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパーモード」を ON
2. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選択
3. 新しいタブを開いて確認

コード変更後は拡張機能カードの「更新」を押し、新しいタブを開き直してください。

## 背景画像の登録

画像は同梱していません。次のどちらかで用意してください(両方使うと合算され、ランダム表示されます)。

- **設定画面からアップロード**: 拡張機能の「オプション」で曜日ごとに追加・差し替え・削除(IndexedDB に保存)
- **フォルダで登録**: `images/` に画像を置き、`config.js` の `BUNDLED_IMAGES` に曜日ごとのファイル名を書いて「更新」
  (`images/` は Git 管理対象外)

## 上部バーの色(任意)

1. `chrome://extensions` →「パッケージ化されていない拡張機能を読み込む」→ `theme/` を選択(本体とは別に読み込む)
2. 色は `theme/manifest.json` の `theme.colors`(RGB 配列)で調整し、「更新」

## 構成

```
├── manifest.json            # 拡張機能の定義
├── newtab.html / .css / .js # 新しいタブ(背景 + ショートカット)
├── options.html / .css / .js# 設定画面
├── config.js                # フォルダ登録する画像の設定
├── lib/                     # storage / weekday / particles / pool
├── images/                  # 背景画像(各自で用意)
└── theme/                   # 上部バー用の Chrome テーマ(別パッケージ)
```

## 権限

`storage` / `favicon` / `unlimitedStorage` のみ。ホスト権限や外部通信は使いません。

## 技術

素の HTML / CSS / JavaScript (ES Modules)、ビルド工程なし。
